# Fast Service Electro Mechanical Website

Modern React + Vite website with separated pages and reusable components.

## Run locally

```bash
npm config set registry https://registry.npmjs.org/
npm install --registry=https://registry.npmjs.org/
npm run dev
```

Open http://localhost:3000

## Structure

- `src/pages` - Home, About, Services, Gallery, Contact pages
- `src/components` - reusable sections and UI components
- `src/data.ts` - editable website content and services
- Admin panel available from the header Admin button
